# ⚽ 足球闹钟App — Soccer Alarm Clock

> 纯净足球赛程提醒工具 · 无广告 · 无需注册 · 不追踪隐私
> Pure football match reminder — No ads, no registration, no tracking.

**最新版本：v2.47** · 安卓平台

---

## 📱 核心功能

| 功能 | 说明 |
|------|------|
| 🕐 **赛程闹钟** | 自定义比赛提醒，到点准时响铃 |
| 📊 **实时比分** | 接入服务器API，实时比分+赛况更新 |
| 🏆 **多联赛支持** | 英超·西甲·意甲·德甲·法甲·中超·欧冠·2026世界杯 |
| ⭐ **关注球队** | 只显示你关心的球队赛程 |
| 🏆 **世界杯专版** | 小组赛+淘汰赛完整对阵图 |
| 🎵 **自定义铃声** | 用自己的音乐做闹钟铃声 |
| 📅 **日历同步** | 一键导入手机系统日历（系统级闹钟，APP被杀也能响） |
| 🌐 **自动时区** | 自动转为北京时间 |
| 🔄 **自动更新检测** | 启动后自动检查新版本 |

## 🛡️ 防杀体系

8层防护，闹钟准时率 99%+：
- **日历闹钟**（核心）→ 写入系统日历，独立于APP运行
- 前台常驻通知 + 双进程守护
- 电池优化白名单引导
- AlarmManager 精确唤醒
- 开机/时区变更自动重算

> 详细防杀原理：[足球闹钟防杀说明](https://足球闹钟.top/anti-kill)
